Diese Instanz setzt keine Analyse-, Werbe- oder Social-Cookies. Deshalb gibt es kein Consent-Banner: nach TDDDG / ePrivacy brauchen nur nicht notwendige Cookies eine Einwilligung.

Technisch notwendig

  • gateway_admin — Session-Cookie für Login (HttpOnly, SameSite=Lax). Ohne diesen Cookie funktioniert die Web-UI nicht.
  • gw_tz — Anzeige-Zeitzone aus dem Browser, damit Zeitstempel lokal stimmen. Speicherdauer ca. 1 Jahr.

Kein Cookie

  • localStorage gw_theme — Hell-/Dunkelmodus, nur auf diesem Gerät, nicht an den Server gesendet.

Schriftarten liegen unter /static/fonts auf diesem Server. Es wird kein Google-Fonts-Request ausgelöst.

This instance sets no analytics, advertising, or social cookies. There is no consent banner: under TDDDG / ePrivacy, only non-essential cookies need consent.

Strictly necessary

  • gateway_admin — session cookie for sign-in (HttpOnly, SameSite=Lax). The web UI does not work without it.
  • gw_tz — display timezone from the browser so timestamps match local time. Kept about 1 year.

Not a cookie

  • localStorage gw_theme — light/dark mode, on this device only, not sent to the server.

Fonts are served from /static/fonts on this server. No Google Fonts request is made.
