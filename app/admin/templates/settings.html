API keys

Global cap on active keys per non-admin user (stops limit bypass via many keys). Platform admins are unlimited. 0 = unlimited for everyone.

Usage pool (budget)

A unit is not one request — it is a budget point burned by prompt size. Default formula: max(min cost, tokens ÷ tokens-per-unit) × model weight. Small “hi” still costs the min (often 1). A long / complex prompt with many tokens costs more. Heavier models can cost more via Models → usage_weight. 0 window hours = pools off. Per-user limit: Users → Edit grant.

Example with defaults (1000 tokens/unit, min 1, weight 1): ~50 tokens → 1 unit · ~3000 tokens → 3 units. Pool limit 100 ≈ one hundred tiny chats or ~33 medium prompts per window — not “100 requests”.
