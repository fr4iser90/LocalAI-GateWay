Privacy

Teams (optional)

Off by default. Users only see their own keys. Turn on only if people should share a key pool.

API keys

Global cap on active keys per non-admin user (stops limit bypass via many keys). Platform admins are unlimited. 0 = unlimited for everyone.

Request rate limits

Set these per user under Users → Edit grant (or on the API key / team): RPM, concurrency, and daily requests. That is the normal way to cap traffic — no token math.

Token budget (optional)

Extra size cap on estimated prompt tokens per rolling window. Leave window at 0 if you only want RPM / daily limits. Per-user max tokens: Users → Edit grant.

Default charge (weights off): budget_charge = max(min tokens/call, estimated_prompt_tokens). Usage logs always store real tokens — never rewritten.

Example: limit 100000 tokens / 5h ≈ many short chats or fewer long prompts. Tiny calls still charge at least the minimum below.

When enabled, Models shows a Budget factor column. Formula then: budget_charge = max(min tokens/call, estimated_prompt_tokens) × factor (factor=1 = unchanged). Logged usage / billing meters stay at real tokens; only the optional grant budget is scaled. Leave unchecked unless you intentionally weight some models differently.

Clients may send auto, auto-quality, or auto-long. The gateway rewrites those to a real catalog id before llama-router. Empty fields use the Halo defaults below. Pin auto as a favorite so IDEs pick it first.
