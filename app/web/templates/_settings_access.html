Registration & teams

With self-registration off, create one-time links under Users → Invite link — only people you invite can sign up.

Email is always required when signing up (password reset, account contact).

Teams (optional)

Off by default. Turn on only if people should share a key pool.

API keys

Max active keys per non-admin user. Platform admins are unlimited. 0 = unlimited for everyone.
